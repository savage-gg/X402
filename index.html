x402

Monetize Anything with HTTP 402

This demo website accepts real micropayments via the open x402 protocol. AI agents and developers can pay per request — no accounts, no API keys, no friction.

How it works

  1. Client requests a paid resource
  2. Server responds with HTTP 402 Payment Required + payment instructions
  3. Client signs a stablecoin payment (USDC on Base)
  4. Server verifies & settles → returns the content
